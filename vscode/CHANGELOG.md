# Changelog

## 0.1.0

- Show the findings from `.linewatch/last.sarif` as markers on the lines: critical as an error, warning as a warning, info as a hint, with the suggested fix in the message.
- Update the markers as soon as a review finishes; a review with no findings clears them, and a half-written file is ignored.
- List the findings in the Problems panel.
- Add the `Linewatch: Reload Findings` command; `Linewatch: Show Status` shows the number of findings.
